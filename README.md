# movielens-project
This project is the final capstone submission for the HarvardX / edX Data Science Professional Certificate course.

## Overview
The goal of this project is to build a movie recommendation algorithm using the 10M MovieLens dataset. The model predicts user ratings for movies and evaluates performance using the Root Mean Squared Error (RMSE).

## Final Result
* **Final Model RMSE:** `0.86402`

## Repository Contents
* `projecto.R`: Standalone R script that downloads the data, trains the models, and computes the final RMSE.
* `MovieLens Project Report.Rmd`: R Markdown document detailing the exploratory data analysis, methodology, results, and conclusion.
* `MovieLens-Project-Report.pdf`: Compiled PDF report generated from the `.Rmd` file.

## Key Packages Used
* `tidyverse`
* `caret`
* `data.table`
